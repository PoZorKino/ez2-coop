ENTROPY : ZERO 2 CO-OP  (for EZ2 1.10.x)

Everyone:  own Entropy : Zero 2 on Steam, then in PowerShell run
             irm https://tool.dexx.moe/install-ez2-coop.ps1 | iex
Host:      desktop shortcut "EZ2 Co-op - Host" -> pick a chapter. A bridge window opens and shows
             connect coop.dexx.moe:276xx      <- send that to your friends. Keep the window open.
Friends:   desktop shortcut "EZ2 Co-op - Join" -> paste the address (or type it in the game console).
No port forwarding, Hamachi or VPN needed - traffic goes through the relay at coop.dexx.moe.

Notes: saving is disabled in multiplayer (the host picks a chapter to start from). Up to 32 players.
